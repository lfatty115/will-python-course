# 🏡 UK House Prices — Exploratory Data Analysis (EDA)

This project explores UK house price trends using publicly available datasets from the HM Land Registry and other official sources.

## 📁 Project Structure

```
data/
    raw/          # Original downloaded datasets
    processed/    # Cleaned datasets
    external/     # Additional supporting data

notebooks/
    01_download_data.ipynb
    02_clean_data.ipynb
    03_eda.ipynb
    04_visuals.ipynb

scripts/
    download.py
    clean.py
    eda.py
    utils.py

visuals/
    charts/
    dashboards/

reports/
    eda_summary.md
```

## 🎯 Goals

- Download and clean UK house price data  
- Explore trends over time  
- Compare regions and property types  
- Visualise key insights  
- Build a reproducible EDA workflow
